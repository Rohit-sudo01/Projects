## 🍽️ Restaurant Website – AWS EC2 Deployment

This project is a responsive restaurant website designed to showcase the restaurant’s menu, food, ambience, story, and reservation/contact information. The website provides a simple and user-friendly interface for customers to explore the restaurant and make reservations.

The project also demonstrates **web server deployment on AWS EC2 using Apache2**, including server configuration, website file deployment, and testing the website through the EC2 instance.

### 🔧 Technologies Used

* HTML5
* CSS3
* JavaScript
* Apache2 Web Server
* AWS EC2
* Linux

### 🚀 Key Features

* Restaurant homepage with hero section
* Popular food/menu section
* Food & ambience gallery
* Restaurant story section
* Contact and reservation form
* Hosted on an AWS EC2 instance using Apache2

### 🎯 Project Objective

The main objective of this project is to build a functional restaurant website and gain practical experience in **Linux server administration, Apache2 configuration, AWS EC2 deployment, and basic web hosting**.
